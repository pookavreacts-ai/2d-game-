# 2D Android Game (GitHub APK build)

A simple offline 2D top-down adventure starter. Build an APK with GitHub Actions.

## Build
1. Upload this folder to a GitHub repository.
2. Open **Actions** and run **Build Android APK** (or push to main).
3. Download the `game-apk` artifact from the completed workflow.

The project uses Godot 4.3 and Android export templates are installed by CI.
